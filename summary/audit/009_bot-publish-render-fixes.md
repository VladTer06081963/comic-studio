# Аудит: Фиксы ошибок публикации и рендера в Telegram-боте

## 1. Контекст
При запуске публикации и повторного рендера старых сценариев через инлайн-кнопки в Telegram-боте возникали ошибки (падение скриптов):
1. `Publish error: Cannot find package 'dotenv'` из-за отсутствия пакета в глобальном контексте.
2. `Render error: not in required initial state` из-за попытки рендера сценария, который уже не в статусе `approved`.

## 2. Что сделано
- Из скриптов `publisher/site.js` и `publisher/social.js` удалён импорт библиотеки `dotenv`.
- В `tg-bot/bot.js` команда запуска публикации переведена на нативный флаг Node 22: `node --env-file=.env scripts/publish_rendered.js`.
- В `tg-bot/bot.js` добавлена строгая проверка статуса перед выполнением действий:
  - `render` работает только для статуса `approved`.
  - `publish` работает только для статуса `rendered`.
- Если статус не совпадает, пользователю отправляется alert-уведомление без запуска дочерних процессов.
