# Аудит: Fast Restyle & UX Fixes

## 1. Контекст
В процессе использования MCP-интеграции и UI были выявлены следующие UX проблемы:
- Ошибка 409 (Conflict) в UI при клике на "Рендер", так как UI не блокировал кнопку и не показывал статус активных фоновых задач.
- Сервер падал с `ENOENT` при попытке очистить `data/.staging/legacy`, если директория не существовала.
- Перерисовка текста (captions) ИИ-агентом или через Web UI требовала полного цикла `revise_scenario -> approve -> render`, который занимал много времени (вызов MiniMax), хотя можно было ограничиться генерацией HTML.

## 2. Что сделано
- **UI:** Интегрирован вызов `/api/jobs` в функцию загрузки табов. Теперь кнопки блокируются во время выполнения задачи и показывается бэйдж "В процессе".
- **Backend:** В `web/lib/scenario_store.js` добавлена проверка `fs.existsSync` для `cleanupLegacyStaging`.
- **Backend:** В эндпоинт `POST /api/scenarios/:id/restyle` добавлена поддержка массива `captions`, что позволяет мгновенно обновлять тексты в JSON без MiniMax.
- **MCP Server:** Добавлен новый инструмент `update_comic_text` (использует `restyle`), позволяющий ИИ-агентам мгновенно переписывать диалоги и менять стили.
- **UI:** Добавлено всплывающее окно "⚡️ Быстрая правка" для `rendered/published` комиксов для мгновенного редактирования текстов.
- Добавлена документация `MCP_GUIDE.md` для подключения локальных клиентов (Claude Desktop, Hermes).

## 3. Статус
Все критические UX-проблемы решены. Новый функционал быстрого обновления текста доступен как для человека (Web UI, Telegram), так и для агента (MCP).
