# Audit: MCP Server Integration (Pre-Phase)

## Текущее состояние (на момент старта 018)

### Конвейер (Comic Studio)
В проекте реализован полный цикл производства комиксов:
- Ингрест через CLI (URL, YouTube, свободный ввод).
- Рендер и публикация (HTML + PNG, загрузка в Notion).
- Web API (`web/server.js`) с эндпоинтами для управления сценариями (`/api/scenarios`).
- Телеграм-бот (`tg-bot/bot.js`) для утверждения, ревизий и рестайлинга баблов.

### Интеграции и Экосистема
- Подключен Notion API для синхронизации сценариев.
- Имеется система крон-джоб для ночных рендеров.
- Локально развернут **LM Studio** с моделью `magnum-picaro`.
- Установлен и настроен **Draw Things MCP** для локальной генерации изображений.

### AiPULT (Фазы 1-3)
- Фаза 1 и Фаза 2 завершены (чат-советник в Web UI, который ищет сценарии по тексту и выдает карточки с кнопками Run).
- Фаза 3 (Голосовой ввод через Telegram MiniApp) описана в `HANDOFF_AiPULT_PHASE_3.md`, но пока **отложена**. Принято решение не смешивать UI-фичу для человека с инфраструктурной фичей (MCP) для ИИ.

## Проблема / Потребность
Существующая архитектура требует "ручного" управления или кликов в Telegram/Web UI. Для реализации автономного **ИИ-агрегатора** (когда локальная модель из LM Studio сама скармливает себе транскрипты, дробит их на сцены и управляет конвейером) необходим машинный интерфейс управления Comic Studio.

## Готовность к внедрению MCP
- REST API в `web/routes/scenarios.js` инкапсулирует всю сложную логику (валидация, JobManager).
- Идеально подходит для создания прослойки (MCP сервера), которая будет принимать Tool calls от ИИ-агента и конвертировать их в локальные HTTP запросы на порт 3000.

## Выводы
Текущая база кода стабильна и готова к добавлению нового независимого компонента `mcp-server`. Архитектура не требует рефакторинга существующих модулей, за исключением возможного добавления эндпоинта `/restyle` в `web/routes/scenarios.js` (так как сейчас эта логика живет только в боте).
