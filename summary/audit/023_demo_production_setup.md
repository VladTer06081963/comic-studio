# Аудит: 023_demo_production_setup

## 1. Цель
Описать и подготовить легковесную конфигурацию проекта Comic Studio для развертывания на минимальных серверах (от 1 ГБ ОЗУ) в рамках "демо-продакшена".

## 2. Что было сделано
- **Документация:** Создан файл `DEMOPRODACTION.md`, содержащий пошаговую инструкцию по установке, настройке (заглушки для тяжелых модулей), запуску процессов через PM2 и конфигурации Nginx.
- **Git Branching:** Создана отдельная ветка `demo-production`, которая предназначена для деплоя на слабых серверах.
- **Оптимизация ветки `demo-production`:**
  - В файле `py/ingest/youtube.py` установлена заглушка (stub) для функции `_fetch_audio_and_transcribe`, чтобы предотвратить локальный запуск тяжелой модели `openai-whisper` и скачивание аудио через `yt-dlp`.
  - Из `py/requirements.txt` удалены ресурсоёмкие зависимости `yt-dlp` и `openai-whisper`.
- **Основная ветка `main`** сохранена в исходном виде со всем функционалом разработки.

## 3. Статус
Завершено. Ветка `demo-production` готова к выкатке на минимальные серверы (например, Oracle Cloud Always Free), а инструкция `DEMOPRODACTION.md` находится в ветке `main` для справки.
