ℹ️ Помощь

🎨 Создание комикса

  • Перейди в таб ✨ Создать
  • Введи URL статьи, YouTube или свободный текст
  • Выбери стиль изображений:
    • 🎬 Cartoon — мультяшный, яркие цвета
    • 🎌 Anime — аниме, японская анимация
    • 📚 Comic — комикс (по умолчанию)
    • 📷 Realistic — фотореализм, 8K
    • 🎨 Watercolor — акварель
  • Нажми Создать сценарий

📋 Управление сценариями

  • Черновики — 🟢 ждут утверждения
  • Утверждённые — 🔵 готовы к рендеру
  • Готовые — 🎬 отрендеренные
  • Комиксы — 🖼️ все выпуски

🔄 Revision

  1. На карточке сценария нажми 🔄 Revision
  2. Введи пожелания или выбери пример
  3. Нажми Revision

Примеры правок:

  • Убрать панель 2
  • Сделать более смешным
  • Добавить драмы в 3 панель
  • Изменить концовку
  • Добавить персонажа

Badge 💬 N запросов показывает сохранённую историю. Revision запускает LLM-регенерацию и снимает approval до ручного re-approval.

🔐 Доступ

  • По умолчанию Web server доступен только на 127.0.0.1
  • Remote mode требует API token и разрешённый origin
  • Token хранится только до закрытия browser session

🚀 Контент

  • ✅ Утвердить — перевести в статус «Утверждён»
  • ❌ Отклонить — перевести в статус «Отклонён»
  • 🔄 Revision — для approved/rendered, атомарно отзывает approval и запускает LLM
  • 🎨 Remix — только для published, создаёт новый draft
  • 🔄 Re-render — атомарно заменить только rendered comic
  • Published — read-only; изменение потребует нового remix draft

💡 Подсказки

  • Подписи в комиксах — только на русском
  • Правки сохраняются как история — можно дополнять
  • Все сценарии автоматически обновляются каждые 10 секунд
