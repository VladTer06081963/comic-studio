# Proposal: Edit Scenario UI

## Проблема
В Web UI нет возможности редактировать сценарии. Telegram бот имеет ✏️ кнопку, но Web — нет.

## Решение
Добавить кнопку ✏️ Редактировать в Web UI с модальным окном для ввода правки.

## UX Flow
1. Пользователь нажимает ✏️ Редактировать на карточке
2. Открывается модальное окно с:
   - Textarea для правки
   - Примеры типовых правок
   - Кнопка "Сохранить"
3. Правка добавляется к сценарию как `feedback[]`
4. Карточка обновляется с индикатором количества правок

## Impact
- Расширение правок: Web UI ↔ Telegram бот
- Удобный UX с примерами
