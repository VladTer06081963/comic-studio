# Proposal: Image Style Selector UI

## Проблема
Пользователи не могут выбрать стиль изображений через UI — только через CLI.

## Решение
Добавить выбор image_style в:
- Telegram бот (inline-кнопки)
- Web UI (select/кнопки)

## Стили
- cartoon, anime, comic, realistic, watercolor

## Impact
- Улучшен UX
- Больше контроля у пользователей
