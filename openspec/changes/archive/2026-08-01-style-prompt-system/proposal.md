# Proposal: Система стилей для генерации изображений

## Проблема
Промпты для MiniMax image-01 генерируются LLM без стандартизации. Результат непредсказуем, сложно получить нужный визуальный стиль.

## Решение
Создать систему шаблонов стилей (`STYLE_TEMPLATES`), которые подставляются в промпт панели.

## Стили
- **cartoon** — мультяшный, яркие цвета, анимационный
- **anime** — аниме, японская анимация, cel shaded
- **comic** — комикс, жирные линии, halftone dots
- **realistic** — фотореализм, 8K, cinematic
- **watercolor** — акварель, мягкие края

## Impact
- Предсказуемый результат генерации
- Лёгкая расширяемость новых стилей
- Улучшенное качество комиксов
