# Proposal: Caption Style Selector UI

## Проблема
Пользователи не могут выбрать caption style (стиль подписей) через UI — только через CLI.

## Решение
Добавить кнопки выбора caption_style в:
- Telegram бот
- Web UI

## Стили подписей
- 💬 bubble (по умолчанию)
- ⭐ star (взрыв POW!)
- 🏰 gothic
- 💥 boom
- 📝 memo
- 📊 bar

## Impact
- Полный UX для создания комиксов
- Сохранение в scenario.style
