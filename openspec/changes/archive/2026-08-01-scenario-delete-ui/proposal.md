# Proposal: Delete Scenario UI

## Проблема
Нет возможности удалять сценарии через UI.

## Решение
Добавить кнопку удаления в:
- Telegram бот (с подтверждением)
- Web UI (с confirm modal)

## UX Flow

### Telegram
1. Кнопка 🗑 Удалить в карточке
2. Inline подтверждение: "Точно удалить?" → ✅ Да / ❌ Нет

### Web UI
1. Кнопка 🗑 в карточке
2. Confirm modal с предупреждением

## Impact
- Удаление файла сценария
- Удаление связанных файлов (comics, panels)

## Security
- Подтверждение обязательно
- Только авторизованные пользователи
