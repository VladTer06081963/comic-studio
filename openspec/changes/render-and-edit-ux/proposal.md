# Proposal: Render & Edit UX Improvements

## Проблема
1. В Web UI нет кнопки 🎨 Рендер для утверждённых сценариев
2. Нет способа изменить seed для рандомизации через UI
3. Telegram edit — простой ввод текста, неудобно

## Решение

### 1. Render в UI
Добавить кнопку 🎨 Рендер на карточки `approved`, `rendered`, `published`.

### 2. Seed в UI/Telegram
- Кнопка 🎲 Изменить seed на карточке
- Опция в форме редактирования

### 3. Telegram Edit как карточка
- Inline-кнопки для типов правок:
  - 📝 Общий фидбек
  - 🎲 Изменить seed
  - 🔄 Перерендерить
  - ✏️ Редактировать промпт панели
  - ❌ Отмена

## Impact
- Полный UX в обоих интерфейсах
- Удобный re-render с разным seed
