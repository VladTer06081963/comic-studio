# Руководство по MCP: Как объяснить это новичку 🧠🔌

Model Context Protocol (сокращенно **MCP**) — это как USB-кабель, но только для искусственного интеллекта. 

Представьте себе умную нейросеть (например, Claude или модель в вашем LM Studio) как гениального человека, который заперт в пустой комнате без окон. Он очень умный, он умеет писать тексты, придумывать истории и переводить, но **он ничего не знает о внешнем мире и у него нет рук**, чтобы что-то сделать на вашем компьютере.

Раньше, чтобы этот "мозг" что-то сделал, вам приходилось работать курьером: 
1. Скопировать текст с вашего компьютера.
2. Вставить в чат с ИИ.
3. Дождаться ответа.
4. Скопировать его ответ и вставить в свою программу (например, нажать кнопку рендера).

## Что делает MCP?

MCP дает этому мозгу "Руки" и "Глаза". 

Благодаря MCP, нейросеть может сама "дотянуться" до файлов на вашем компьютере, прочитать их, изменить и даже нажать нужные кнопки в программах. И всё это безопасно, потому что вы сами решаете, какие "руки" ему выдать.

Каждое такое разрешение называется **Tool** (Инструмент). 

## Как это работает в Comic Studio?

Мы только что написали **Comic Studio MCP Server** (ту самую папку `mcp-server`). 
Это программа-переводчик. Она понимает язык, на котором говорит ИИ, и переводит его в команды для вашей программы по созданию комиксов.

Мы выдали ИИ следующие "Инструменты" (Tools):
- `list_scenarios`: ИИ может сам заглянуть в вашу папку с комиксами и посмотреть, что там лежит (черновики, готовые и т.д.).
- `get_scenario`: ИИ может прочитать конкретный сценарий от начала до конца, чтобы понять сюжет.
- `create_comic`: ИИ может сам напечатать новый сценарий (написать текст, выбрать стиль баблов) и сохранить его как черновик.
- `approve_scenario`: ИИ может сказать "Утверждаю, пускаем в печать!".
- `render_comic`: ИИ может нажать кнопку "Отрендерить картинки".
- `revise_scenario`: ИИ может внести правки в сюжет, если ему что-то не понравилось.
- `restyle_comic`: ИИ может "на лету" поменять стиль баблов с текстом (например, сделать их готическими или в виде взрыва), не перерисовывая картинки.
- `resolve_intent`: ИИ может искать сценарии просто по названию или смыслу, используя наш умный поиск AiPULT.
- `read_comic_image`: ИИ может **запросить саму картинку** (весь комикс целиком или конкретную панель), чтобы посмотреть на неё своими "глазами" (через Vision) и оценить результат!

## Пример из жизни (Ваш ИИ-Агрегатор)

Как это будет выглядеть на практике:
1. Вы запускаете ИИ (например, в Claude Desktop) и говорите ему: *"Посмотри мои последние черновики, выбери самый смешной и отправь его на рендер"*.
2. ИИ по "кабелю" MCP вызывает инструмент `list_scenarios`.
3. Наш сервер отдает ему список ваших черновиков.
4. ИИ читает их, выбирает нужный.
5. ИИ по тому же кабелю вызывает инструменты `approve_scenario` и `render_comic`.
6. Вы получаете готовый комикс, даже не открывая интерфейс Comic Studio!

## Как подключить ИИ к нашему MCP серверу?

### Если вы используете Hermes Desktop (ваше основное приложение)
Так как Hermes поддерживает интеграцию с локальными моделями и MCP, зайдите в его **Настройки (Preferences) -> MCP Servers** (или в соответствующий файл конфигурации).
Там нужно указать, как запускать наш сервер. Параметры всегда одинаковые:
- **Команда (Command):** `node`
- **Аргументы (Args):** `/Users/vladteresena/Projects/comic-studio/mcp-server/index.js`

### Если вы используете Claude Desktop для Mac
Откройте файл настроек (обычно это `claude_desktop_config.json`) и добавьте:

```json
{
  "mcpServers": {
    "comic-studio": {
      "command": "node",
      "args": [
        "/Users/vladteresena/Projects/comic-studio/mcp-server/index.js"
      ]
    }
  }
}
```

Как только вы перезапустите ваш ИИ-клиент (Hermes или Claude), он увидит значок подключения. Это значит, что он "подключился" к Comic Studio и теперь имеет над ним власть (в рамках тех 7 команд, что мы разрешили).

Вот и всё! MCP — это просто стандартизированный способ дать нейросетям доступ к вашим программам.
