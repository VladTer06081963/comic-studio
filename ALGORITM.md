## Пошаговый алгоритм (5 минут от идеи до комикса)

```
Шаг 1: ИДЕЯ
────────────────────────────────────────────────────
Пользователь → /freeform или бот → Идея
                    │
                    ▼
Шаг 2: КОНТЕКСТ
────────────────────────────────────────────────────
URL      → fetch_url()     → чистый текст
YouTube  → transcribe_youtube() → текст (30k макс)
Текст    → save_freeform() → .md файл
                    │
                    ▼
Шаг 3: СЦЕНАРИЙ
────────────────────────────────────────────────────
Текст → generate_scenario() → LLM (MiniMax Text-01)
                    │
                    ▼
data/scenarios/draft/<id>.json
status: "draft"
                    │
                    ▼
Шаг 4: УТВЕРЖДЕНИЕ (ручное)
────────────────────────────────────────────────────
Пользователь в Telegram:
  ✅ → approve() → data/scenarios/approved/<id>.json
                    │
                    ▼
data/scenarios/approved/<id>.json
status: "approved"
                    │
                    ▼
Шаг 5: РЕНДЕР
────────────────────────────────────────────────────
validate_approved() → gate check
generate_image() × 3-4 → MiniMax image-01
                    │
                    ▼
data/comics/<id>/panel_1.png
data/comics/<id>/panel_2.png
data/comics/<id>/panel_3.png
                    │
                    ▼
assemble_comic() → minimax-comic skill
                    │
                    ▼
data/comics/<id>.png
status: "rendered"
                    │
                    ▼
Шаг 6: ПУБЛИКАЦИЯ
────────────────────────────────────────────────────
publish() → POST site (JSON + base64)
          → Notion (если настроен)
status: "published"
published_url: "https://..."
                    │
                    ▼
data/archive/<date>/     ← копия на хранение
```

## Статусы сценария

| Статус | Папка | Значение |
|--------|-------|----------|
| 🟢 draft | `scenarios/draft/` | Новый, ожидает решения |
| 🔵 approved | `scenarios/approved/` | Утверждён, готов к рендеру |
| 🔴 rejected | `scenarios/rejected/` | Отклонён, в архиве |
| 🎨 rendered | `scenarios/rendered/` | Комикс нарисован |
| 🚀 published | `scenarios/published/` | Опубликован на сайте |

---

## Один комикс за 5 минут

```
1. В боте:    ✨ Создать комикс → "Маск летит на Марс"
2. LLM:        генерирует сценарий (~10 сек)
3. Telegram:   приходит карточка сценария
4. Ты:         нажимаешь ✅
5. MiniMax:    рисует 3 картинки (~60 сек)
6. Сборка:     склеивает в PNG (~5 сек)
7. Готово:     комикс в data/comics/
```

## Стили подписей комикса

| Стиль | Описание |
|-------|----------|
| star | Взрывы "POW!", "BAM!" |
| bubble | Облачка диалогов |
| gothic | Готический шрифт |
| boom | Крупные взрывы |
| memo | Стикер-стиль |
| bar | Полоски внизу панели |

## Источники контекста

| Источник | Модуль | Описание |
|----------|--------|----------|
| URL статьи | `py/ingest/url.py` | Парсит HTML, извлекает текст из `<main>` или `<article>` |
| YouTube | `py/ingest/youtube.py` | Субтитры → voicebox (mlx-whisper) → текст |
| Свободный текст | `py/ingest/freeform.py` | Сохраняет .md файл с timestamp |
